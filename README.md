# 📚 AI Study Buddy - Intelligent Learning Assistant

An AI-powered study companion that transforms PDF documents into interactive learning experiences with automatic quiz generation, personalized explanations, and comprehensive study modes.

## 🎯 Overview

AI Study Buddy revolutionizes the learning experience by leveraging advanced AI to analyze study materials, generate practice questions, and provide personalized explanations. Perfect for students, educators, and lifelong learners.

## ✨ Key Features

### 📄 Smart PDF Analysis
- Upload any PDF document
- Intelligent text extraction and chunking
- Content preview and statistics
- Automatic text cleaning and formatting

### 🎓 AI-Powered Quiz Generation
- **Multiple Choice Questions** - 4-option MCQs with explanations
- **True/False Questions** - Quick comprehension checks
- **Short Answer Questions** - Test deeper understanding
- Unlimited quiz regeneration
- Instant feedback and explanations

### 💡 Multiple Study Modes

#### 1. **Explain Mode** (Default)
- Clear, detailed explanations
- Real-world examples
- Step-by-step breakdowns

#### 2. **Quiz Mode**
- Interactive question-answer format
- Immediate feedback
- Tracks correct/incorrect answers

#### 3. **Review Mode**
- Comprehensive summaries
- Key concepts extraction
- Study notes generation

#### 4. **Practice Mode**
- Guided problem-solving
- Hints and step-by-step solutions
- Practice problem generation

#### 5. **Summarize Mode**
- Quick content overviews
- Main points extraction
- Essential information focus

### 📊 Session Management
- Save conversation history
- Track study sessions
- View past learning activities
- Export session data (JSON)
- Topic tracking and organization

### 🎨 Beautiful User Interface
- Clean, modern design
- Responsive layout (mobile-friendly)
- Smooth animations
- Intuitive navigation
- Dark-themed aesthetic
